## Project and reserve

CAVE is inspired by cavemen, gold miners and discovery. The project website provides a token buying guide and links to the CAVE/SOL market on Raydium.

The founder holds a project reserve. Detailed use allocations and a release schedule have not yet been finalized. No token lock or vesting arrangement is claimed here. Current wallet balances change and must not be treated as the original distribution.
